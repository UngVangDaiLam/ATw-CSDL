Cấu hình pgAudit — Rà lại mức log

Quản lý các class log của pgAudit: write, ddl, role, cân nhắc bật thêm read chọn lọc cho bảng nhạy cảm. Cấu hình hiện tại được đọc từ postgresql.conf.

Cấu hình hiện tại

postgresql.conf
postgres/conf/postgresql.conf 
pgaudit.log = 'read, write, role, ddl, misc_set'
pgaudit.log_relation  = on
pgaudit.log_parameter = off   # TẮT có chủ đích — bảo vệ lớp 2
pgaudit.log_catalog   = off   # Tránh log rác từ catalog
pgaudit.log_statement_once = off
pgaudit.log_level     = log

Audit Log Classes

Bật/tắt từng class để xem trước giá trị pgaudit.log sẽ được sinh ra

read ĐANG BẬT
SELECT / COPY FROM — đọc dữ liệu
Sinh log rất nhiều — riêng seed 6000 khách hàng → ~47.000 dòng. Cân nhắc bật chọn lọc theo bảng nhạy cảm bằng pgaudit.role.

Bật READ chọn lọc cho bảng nhạy cảm

Thay vì bật read toàn cục (rất "ồn ào"), có thể dùng pgaudit.role + OBJECT AUDIT để chỉ log SELECT trên các bảng nhạy cảm.

write BẬT
INSERT / UPDATE / DELETE / TRUNCATE / COPY TO
Nên bật — theo dõi mọi thay đổi dữ liệu
ddl BẬT
Toàn bộ DDL — CREATE / ALTER / DROP TABLE, INDEX, …
Nên bật — phát hiện thay đổi cấu trúc CSDL trái phép
role BẬT
GRANT / REVOKE / CREATE ROLE / ALTER ROLE / DROP ROLE
Nên bật — theo dõi thay đổi phân quyền
misc_set BẮT BUỘC
Các câu SET — đặc biệt SET ROLE nv_xxx
Đừng tắt! Mất khả năng quy trách nhiệm theo nhân viên. Cột user trong log luôn là app_user; chỉ nhờ SET ROLE mà analyzer mới biết ai đang thao tác.
function TẮT
Gọi hàm (EXECUTE / DO)
Tùy chọn — sinh log rất nhiều, cân nhắc kỹ

Cấu hình sẽ được sinh ra

pgaudit.log = 'read, write, role, ddl, misc_set'

            Cảnh báo Bảo mật: pgaudit.log_parameter
          

        

        

          

            
pgaudit.log_parameter hiện đang TẮT (off) — đây là cố ý.

            
Nếu bật lên, giá trị tham số (số CCCD, khóa truyền vào pgp_sym_encrypt, mật khẩu) sẽ bị ghi PLAINTEXT vào file log → phá vỡ toàn bộ lớp mã hóa (Lớp 2).

            

              pgaudit.log_parameter = off
              → Dòng AUDIT kết thúc bằng <not logged>
